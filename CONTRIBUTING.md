# Contributing

## Layout

```
src/            React + TypeScript frontend (Vite)
src/bindings.ts generated by tauri-specta: do not edit
src-tauri/      Tauri app: commands, capabilities, bundling config
crates/core/    Tauri-independent logic (change sets, inverse SQL, clipboard formats)
crates/pg/      PostgreSQL access (tokio-postgres)
e2e/            Playwright tests with Tauri IPC mocked
dev/seed/       SQL loaded by compose.yaml
```

Put logic in `crates/` whenever it does not need Tauri, so it can be tested without a WebView.

## Tooling

| Area                    | Tool                                                                    |
| ----------------------- | ----------------------------------------------------------------------- |
| Rust format / lint      | rustfmt, Clippy (`[workspace.lints]` in `Cargo.toml`)                   |
| Rust tests              | cargo-nextest, testcontainers (PostgreSQL), insta (snapshots), proptest |
| Rust dependency audit   | cargo-deny (`deny.toml`)                                                |
| Frontend format / lint  | oxfmt, oxlint with type-aware rules                                     |
| Frontend tests          | Vitest + Testing Library (happy-dom), Playwright for E2E                |
| Rust → TypeScript types | tauri-specta                                                            |
| Git hooks               | lefthook                                                                |

### Snapshots

When a snapshot test fails because the output changed on purpose, review and accept it with
`cargo insta review` (install with `cargo install cargo-insta`).

### PostgreSQL versions

Integration tests use `PG_IMAGE_TAG` (default `17-alpine`). CI runs 12 and 18 on every PR and
12 through 18 nightly.

### Adding a Tauri command

1. Add the function in `src-tauri/src/commands.rs` with `#[tauri::command]` and `#[specta::specta]`.
2. Register it in `specta_builder()` in `src-tauri/src/lib.rs`.
3. Run `mise run bindings` and commit `src/bindings.ts`. CI fails if it is out of date.
4. Allow it in `src-tauri/capabilities/` if needed.

## Commits and pull requests

PR titles follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat: ...`,
`fix: ...`), checked in CI. PRs are squash-merged, and release-please builds the changelog and
version from those titles.
